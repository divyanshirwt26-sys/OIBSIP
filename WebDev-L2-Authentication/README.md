# AuthSphere — Authentication Interface Demo

**Oasis Infobyte | Web Development & Designing Internship**

**Level 2 — Task 4: Login Authentication System**

## Project Overview

AuthSphere is a responsive frontend demonstration of a login and registration interface, developed using HTML5, CSS3, and JavaScript.

It demonstrates form validation, interactive UI states, and navigation between authentication screens.

**Important:** This project is a frontend prototype, not a production authentication system. It does not create real accounts, verify identities, or securely authenticate users.

## Technologies Used

- HTML5 — Form structure and semantic elements
- CSS3 — Responsive layouts and styling
- JavaScript — Form validation, event handling, and interface state management

## Features

- Sign In and Sign Up interfaces
- Email input validation
- Password length validation
- Password confirmation during registration
- Show/hide password functionality
- Demo dashboard after valid form submission
- Return to Sign In functionality
- Responsive desktop and mobile design

## How to Run

1. Clone or download the OIBSIP repository.
2. Open `WebDev-L2-Authentication`.
3. Launch `index.html` in a browser or with VS Code Live Server.
4. Explore the registration and login interface using invented test credentials.

No backend or external dependencies are required.

## Testing

The interface was tested for form validation, password visibility, confirmation matching, screen transitions, responsive layouts, and demo session reset.

## Security Limitations

- No backend authentication
- No account database
- No password storage
- No secure session management
- No protected server resources

The dashboard is a UI demonstration only. Real authentication would require a trusted backend or authentication provider.
