# Personal Developer Portfolio

**Oasis Infobyte — Web Development & Designing Internship**

**Level 1 | Task 2: Personal Portfolio Website**

## Project Overview

This project is a responsive personal developer portfolio designed to showcase my background, technical skills, and software development projects.

I created a dark and futuristic interface to reflect my interests in software engineering, robotics, and emerging technologies.

The portfolio is also intended to serve as a foundation for my professional online presence.

## Technologies Used

- HTML5 — Semantic website structure
- CSS3 — Styling and visual design
- CSS Grid and Flexbox — Responsive layouts
- CSS Animations — Decorative visual effects
- Media Queries — Mobile and tablet responsiveness

## Features

- Sticky navigation bar with smooth scrolling
- Hero section with a futuristic CSS illustration
- About Me section introducing my academic background
- Technical skills overview
- Featured project cards
- Contact section with GitHub profile link
- Responsive layouts for desktop, tablet, and mobile
- Reduced-motion accessibility support

## Featured Projects

### HueMory
A visual diary concept combining mood tracking, personal reflections, and a conversational avatar.

### Smart Maintenance Parts Assistant
A voice-controlled robotic assistant developed using Python and DobotLab, demonstrated in virtual and physical environments.

### StudyFlow
A responsive landing page for a fictional student productivity platform, developed as Level 1 Task 1 of this internship.

## How to Run

1. Clone or download the OIBSIP GitHub repository.
2. Navigate to the `WebDev-L1-Portfolio` folder.
3. Open `index.html` in a browser.
4. Alternatively, launch it using Live Server in VS Code.
