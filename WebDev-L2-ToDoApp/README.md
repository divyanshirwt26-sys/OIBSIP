# TaskNest — Personal Productivity Dashboard

**Oasis Infobyte | Web Development & Designing Internship**

**Level 2 — Task 3: To-Do Web Application**

## Project Overview

TaskNest is a responsive task management application developed using HTML5, CSS3, and JavaScript. It helps users organize tasks, assign priorities, track progress, and manage daily activities.

The application uses browser localStorage to preserve tasks between page refreshes.

## Technologies Used

- HTML5 — Application structure
- CSS3 — Responsive interface and styling
- JavaScript — Task management and dynamic interactions
- localStorage — Browser-based data persistence

## Features

- Create tasks with titles, descriptions, and priorities
- Edit and delete existing tasks
- Mark tasks as completed or pending
- Search and filter tasks
- Track total, pending, and completed tasks
- Visual progress indicator
- Save tasks between browser sessions
- Responsive desktop and mobile layouts

## How to Run

1. Clone or download the OIBSIP repository.
2. Open the `WebDev-L2-ToDoApp` folder.
3. Open `index.html` using a browser or VS Code Live Server.
4. Create and manage tasks using the dashboard.

No external dependencies are required.
