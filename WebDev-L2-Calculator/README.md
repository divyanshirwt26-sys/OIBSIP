# CalcNova — Interactive Calculator

**Oasis Infobyte | Web Development & Designing Internship**

**Level 2 — Task 1: Calculator**

## Project Overview

CalcNova is a responsive, browser-based calculator developed using HTML5, CSS3, and JavaScript. It provides essential arithmetic functionality through a modern interface with keyboard support and calculation history.

## Technologies Used

- HTML5 — Semantic structure
- CSS3 — Styling, Grid, Flexbox, and responsive design
- JavaScript — Calculation logic, DOM manipulation, and event handling

## Features

- Addition, subtraction, multiplication, and division
- Decimal and negative number support
- All Clear (AC) and backspace functionality
- Keyboard input support
- Calculation history with a clear option
- Division-by-zero error handling
- Responsive desktop and mobile layouts

## How to Run

1. Clone or download the OIBSIP repository.
2. Open the `WebDev-L2-Calculator` folder.
3. Open `index.html` in a browser or launch it using VS Code Live Server.
4. Use the on-screen buttons or keyboard to perform calculations.

No external dependencies are required.

## Testing

The calculator was tested using arithmetic operations, decimal numbers, negative values, division by zero, clearing and editing inputs, keyboard interactions, and mobile responsiveness.

Calculation history is stored in memory and resets when the page is refreshed.
