# StudyFlow — Student Productivity Landing Page

**Oasis Infobyte Internship | Web Development & Designing**

**Level 1 — Task 1: Landing Page**

## Project Overview

StudyFlow is a responsive landing page for a fictional student productivity platform designed to help students organize assignments, plan study sessions, and track academic progress.

The project focuses on creating a clean, accessible, and user-friendly website using HTML5 and CSS3.

## Technologies Used

- HTML5 — Website structure and semantic elements
- CSS3 — Styling, layouts, and responsive design
- CSS Flexbox and Grid — Component alignment and layout
- CSS Media Queries — Mobile and tablet responsiveness

## Features

- Sticky navigation bar with section links
- Hero section with a call-to-action button
- Student dashboard preview
- Feature cards highlighting the platform's benefits
- How It Works section
- About section
- Footer with navigation and demo contact information
- Responsive layout for desktop, tablet, and mobile

## How to Run

1. Download or clone the repository.
2. Open the `WebDev-L1-LandingPage` folder.
3. Open `index.html` in a browser.
4. Alternatively, use the Live Server extension in VS Code.

## Testing

The website was tested locally using Live Server.

- Desktop layout visually reviewed
- Navigation and section links tested
- Mobile-width responsiveness checked
- Layout and element alignment reviewed

## Learning Outcomes

Through this project, I practiced structuring a website using semantic HTML, creating layouts with CSS Grid and Flexbox, designing responsive interfaces, and maintaining a consistent visual identity.

## Project Note

StudyFlow is a landing-page prototype. The dashboard is a visual demonstration and does not currently provide interactive task management functionality.
