# The Visionary — Tribute to Dr. A. P. J. Abdul Kalam

**Oasis Infobyte | Web Development & Designing Internship**

**Level 2 — Task 2: Tribute Page**

## Project Overview

The Visionary is a responsive tribute website dedicated to Dr. A. P. J. Abdul Kalam, India's 11th President, scientist, and educator.

The project presents his life, achievements, and contributions through an elegant editorial-style interface.

## Technologies Used

- HTML5 — Semantic structure and content
- CSS3 — Styling, typography, and responsive design
- CSS Grid and Flexbox — Page layout
- Media Queries — Mobile responsiveness

## Features

- Hero section with a portrait and introduction
- Biography and historical background
- Timeline highlighting six milestones
- Contributions to science, education, and leadership
- Smooth section navigation
- Responsive desktop and mobile layouts
- External biography reference
